# Windows-та деректерді сақтап жаңарту

Бұл жаңарту жаңа «Актив жүктемесі» бөлімін қосады. Бұрынғы SQLite жиындарында жүктеме өрісі жоқ болса, бағдарлама оны бос тізім ретінде оқиды. Өтінімдер, ресми лоттар және журналдар сақталады.

1. Қосымша іске қосылған қара CMD терезесінде **Ctrl+C**, қажет болса **Y → Enter** басып, серверді тоқтатыңыз.
2. Бұрын жұмыс істеген жоба қалтасындағы **data** қалтасының көшірмесін басқа жерге сақтаңыз. Сервер тоқтаған соң ғана көшіріңіз. Көшірмеге `qarjy.sqlite`, бар болса `qarjy.sqlite-wal` және `qarjy.sqlite-shm` бірге кіреді.
3. GitHub-та `qarjy-control-mvp` тармағының жаңа ZIP-нұсқасын жүктеп, **бөлек уақытша қалтаға** шығарыңыз. Сілтеме: https://github.com/khankelditurysbek-hue/literate-tgg/archive/refs/heads/qarjy-control-mvp.zip
4. Жаңа қалтадағы `package.json` тұрған жердің **ішіндегі барлық бастапқы файлдар мен қалталарды** көшіріңіз. Бұрынғы жұмыс істеген жобаның ішіне қойып, сәйкес файлдарды ауыстыруды растаңыз. Жобаның ескі қалтасын түгел жоймаңыз. Жаңа ZIP ішінде `data`, `node_modules`, `.env.local` жоқ; ескі қалтадағы осы жергілікті файлдар қалады.
5. Бұл жаңартуда тәуелділік нұсқалары өзгермеген, бұрынғы `node_modules` жарайды. CMD-ны ескі жұмыс жобасының ішінен ашып:

```bat
npm run db:init
npm run demo:seed
npm run dev
```

6. Браузерде `http://localhost:3000` ашып, **Ctrl+F5** басыңыз.
   `npm run demo:seed` нақты дерекке тимей, DEMO-ға тек жетіспейтін үлгі ID-лерін қосады. Қолданыстағы DEMO түзетулерін ауыстырмайды. UI-дегі «Мысалды қайта жүктеу» бүкіл DEMO-ны қалпына келтіреді, сондықтан өз өзгерістеріңіз бар болса, толтыру командасын қолданыңыз.

7. Алдымен «Нақты деректермен сынақ» бөліміндегі бұрынғы лотыңыз сақталғанын тексеріңіз. «Актив жүктемесі» бөліміне өтіңіз → «Шиелі аудит кейсін қарау» → дерек пен шектеулерді оқыңыз → «Нақты дерекке қосу».
