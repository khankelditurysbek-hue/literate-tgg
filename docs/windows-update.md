# Windows-та Value Gate 2-ге деректерді сақтап жаңарту

Бұл нұсқа PDF/OCR, санға байланысты құжат дәлелі, төрт есеп профилі, нарық медианасы және нақты 010 бағдарламаның сынағын қосады. **Жаңа тәуелділіктер бар:** ескі `node_modules` өздігінен жеткіліксіз.

1. Қара сервер терезесінде **Ctrl+C**, сұраса **Y → Enter** басып тоқтатыңыз.
2. Бұрынғы жоба ішіндегі **data** қалтасының көшірмесін басқа жерге сақтаңыз. Бар болса `qarjy.sqlite-wal`, `qarjy.sqlite-shm` файлдарын бірге сақтаңыз.
3. Жаңа ZIP-ті жүктеп, бөлек уақытша қалтаға шығарыңыз: https://github.com/khankelditurysbek-hue/literate-tgg/archive/refs/heads/qarjy-control-mvp.zip
4. Жаңа `package.json` тұрған қалтаның **ішіндегі файлдар мен қалталарды** бұрынғы жұмыс жобаңыздың ішіне көшіріп, код файлдарын ауыстырыңыз. Ескі жобаны түгел жоймаңыз; **data қалтасын өшірмеңіз**. Жаңа ZIP ішінде дерекқор мен `node_modules` жоқ.
5. Жаңартылған **START-WINDOWS.cmd** файлын ашыңыз. Ол lockfile өзгергенін тексеріп, қажет болса `npm ci` арқылы PDF/OCR кітапханаларын орнатады. Алғашқы жаңарту кезінде интернет керек. Келесі іске қосуда lockfile өзгермесе бұл қадам қайталанбайды.
6. `Ready` шыққан соң `http://localhost:3000` ашып, **Ctrl+F5** басыңыз. Терезені ашық ұстаңыз.
7. Жаңа «Тексеру үстелі» ашылады. **DEMO** режимінде 6 сценарий бар. **Нақты бағдарлама сынағы** бөлімінде ресми 010 бағдарламаның 12 ұяшықтағы салыстыруы көрінеді.
8. Бұрынғы нақты лотыңыз бен өтінімдеріңіз жоғалмайды: сол жақ төменгі **Бұрынғы жұмыс кеңістігі** сілтемесінде сақталады. Жаңа үстелдегі **Бұрынғы өтінімдерді көрсету** арқылы өтінімді көшіріп тексеруге болады; ескі «расталды/келісім» белгілері дәлел ретінде қабылданбайды.

Қолмен іске қосу баламасы:

```bat
npm ci
npm run db:init
npm run demo:seed
npm run dev
```

OCR модельдері `resources/ocr` ішінде бар. Орнатылған соң құжат мәтінін тану сыртқы ЖИ сервисінсіз жергілікті орындалады.

Құжатты жүктемес бұрын ЖСН, телефон және жеке мекенжайларды алып тастаңыз. Жаңа есеп файлдың түпнұсқалығын, ЭЦҚ немесе заңды келісім өкілеттігін растамайды.
