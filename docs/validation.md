## Chromium сценарийлерінің қамтуы

1. Өтінім жасау, өзгерту және жою; актив пен екі балама енгізу; 20 жоспарланған / 12 жарамды бос актив → 8 негізделген жаңа дана; салыстырмалы TCO; дәлелсіз нақты үнем көрсетілмеуі; шешім журналын жазу және reload-тан кейін сақтау; API нұсқа қақтығысы HTTP 409; XLSX жүктеп мазмұнын оқу; CSV импорт және растау; нақты / DEMO оқшаулау; desktop / mobile көріністер; мәзір; браузердің орындалу қателерінің болмауы.
2. Әдістеме мен енгізу жоспарын сақтау; сыни бағалау; шартты DEMO ЖИ журналын тек форма тесті ретінде енгізу; ресми сынақ жазбасы және ішкі дерек жеткіліксіздігі; сынақ XLSX экспорты; жарамсыз URL импорты HTTP 400; төрт бөлімді HTML есепті жүктеп, енгізілген ақпараттың барын тексеру; reload-тан кейін сарапшы бағасының сақталуы.

E2E деректері — уақытша SQLite базасындағы жасанды тест фикстуралары. Олар ағымдағы қолданбаның нақты деректеріне енгізілмеген, ресми материалдар немесе нақты ЖИ диалогтары ретінде ұсынылмайды. Тест аяқталғанда уақытша база жойылады.

Алғашқы екі E2E орындауда селектор қателері болды; олар түзетіліп, жоғарыдағы екі сценарий қайта сәтті орындалды. Алғашқы sandbox орындауда tsx IPC pipe және Next.js child process шектеуі кездесті: тест runner `node --import tsx --test --test-isolation=none` түріне ауыстырылды, build пен браузер тесттері тиісті execution рұқсатымен орындалды. TLS, checksum немесе тест assertions өшірілген жоқ.

## Бұл тексеру нені растамайды

10 нақты лотпен далалық сынақ, заңнаманың ағымдағы редакциясы, тәуелсіз қаржылық аудит, өндірістік қауіпсіздік, жүктемелік сынақ және басқа операциялық жүйелерде орындалу тексерілмеді. Үш нақты пайдаланушы–ЖИ диалогы бар деген тұжырым жасалмайды. Snapshot жариялануы және жаңа task-та қалпына келуі осы сессияда тексерілмеді.

`install_script` және `start_skill` орта draft-ына сәтті сақталды. Draft сақтау командаларды орындау немесе ортаны жариялау болып саналмайды. Орнату командалары осы машинада бөлек орындалды; жариялау пайдаланушы интерфейсінде жасалады.

## Пайдаланушы сұраған толтырылған DEMO

2026-11-02: 34 автоматты тест және 3 Chromium сценарийі өтті; lint, TypeScript және production build сәтті. DEMO-ның үш жүктеме сценарийі, үлгі шешімі мен сыни бағасы валидацияланды. Толтыру командасының ID бойынша қайталанбайтыны және бұрынғы түзетулерді сақтайтыны тексерілді.

Осы бұлттық ортадағы SQLite-нің стандартты backup көшірмесі жасалды, `npm run demo:seed` екі рет орындалды. Нақты жиын payload-ының SHA-256 мәні өзгермегені салыстырылды. Соңғы DEMO: 1 өтінім, 1 шешім, 1 сыни бағалау, 3 жүктеме мысалы. Нақты ЖИ итерациялары ойдан қосылмады. Windows-тағы пайдаланушының базасы осы ортадан өзгертілмеген.

## Value Gate 2: пайдаланушының сыни тексеруінен кейін

2026-11-02. Node.js 24.19.0, Next.js 16.4.4, жүйелік Chromium.

- **67 автоматты тест өтті.** Жаңа тексерулер: сан/файл/бет/үзінді/өлшем байланысы; құжаттағы санның ішкі цифрын басқа санға дәлел ретінде қолдануға тыйым; төрт профиль; құжатталған нөл мен белгісіздің айырмасы; жарамды резерв; бүтін дана мен бөлшек кг/литр дөңгелектеуінің айырмасы; пакет санының бүтіндігі; нарық деректерінің сәйкестігі, тобы/файлы/хэшінің қайталануы; мерзім/ҚҚС/жеткізу; салыстырмалы шығын дәлелі; KRI қамтуы; есеп escaping және CSV formula injection.
- **lint, TypeScript және production build сәтті.** Production маршруттары: негізгі үстел, archive, audit сақтау/Excel экспорт, құжат енгізу/тану/бет суреті; бұрынғы store/files.
- **Қазақша OCR шынымен орындалды:** жасанды PNG-дағы «Жоспар саны 20» / «Қолда бар 12» дұрыс танылды. Бұл OCR сенімділігін барлық құжатта дәлелдемейді; синтетикалық жақсы сапалы суретте орындалу тексеруі.
- **Түсініктеме нақты Chromium PDF ретінде шығарылды: 5 бет.** Үшінші бет визуалды қаралды: DEMO мен бір нақты бағдарлама бөлек белгіленген, кесте қиылмаған. Файлдар `deliverables/explanation.html` және `explanation.pdf`.
- **Нақты дерек:** 010 бағдарламаның портал кестесі мен XLS қосымшасының 12 ортақ ұяшығы, 7 сәйкессіздік. XLS «010 каз» / «010 рус» парақтарының жылдары мен мәндері салыстырылды; бастапқы файл SHA-256 және ұяшық сілтемелері тіркелген. Қай көз дұрыс екенін анықтау немесе артық шығынды дәлелдеу жасалмады.
- **Нақты дерек сақталуы:** осы ортадағы бастапқы SQLite backup жасалды; ескі нақты payload-тың SHA-256 ізі DEMO толтырудан кейін өзгермегені тексерілді. Жаңа real кестесіне сынақ кейстері енгізілмеді. DEMO-ға 6 кейс және 48 анық шартты файл қосылды. Windows-тағы пайдаланушы базасына бұл ортадан қолжетімділік жоқ.

Алты Chromium сценарийі өтті: екеуі жаңа үстелге, төртеуі бұрынғы модульдермен үйлесімділікке арналған. Жаңа сценарийлер профиль есебін, бес бөлім мәртебесін, қайталанған ұсынысты шығару себебін, HTML/Excel мазмұнын, санды бұзғанда қорытындының тоқтауын, reload сақтауын, CAS 409, режимдер арасындағы файлға рұқсат берілмеуін, 390px мобильді сыйымдылықты; нақты PNG OCR, PDF мәтіні мен бет суретін, файл байттарын өзгеріссіз қайтаруды және сыртқы Origin сұрауын тоқтатуды тексерді.

Алғашқы браузер орындауларында пайыздың дәл мәтіні, ішкі summary селекторы және санағыш қосылған батырма атауы бойынша тест қателері болды. Селекторлар нақтыланды, навигацияға тұрақты қолжетімді атау берілді; өтпеген тексерулер жойылған жоқ. Соңғы енгізілген бүтін/бөлшек ережеден кейінгі қайта орындау нәтижесі төменде тіркеледі.

**Расталмағаны:** толық далалық артық көлем валидациясы, жалған дабылдың статистикалық жиілігі, OECD/GAO толық түпнұсқаларын тікелей оқу, ЭЦҚ тексеру, компаниялардың жасырын байланысын анықтау, көп пайдаланушының авторизациясы, өндірістік қауіпсіздік аудиті. Жаңартылған Windows helper-дің lockfile жаңарту тармағы Windows-та жеке орындалып тексерілген жоқ; бұрынғы helper-дің нақты ашылуы пайдаланушы скриншотымен расталған.
