# Тапсыруға арналған материалдар жобасы

- `explanation.pdf` — нақты Chromium-да шығарылған 5 беттік түсініктеме. DEMO және нақты бағдарлама сынағы бөлек белгіленген.
- `explanation.html` — сол түсініктеменің өңделетін/қайта басылатын нұсқасы.
- `real-program-010-results.csv` — бір нақты 010 бағдарламаның 12 ортақ ұяшығы, 7 сәйкессіздік, ресми сілтемелер мен дерек алынған күн.
- `preview.png` — жаңа интерфейс; тестте алғашқы сан әдейі бұзылғандықтан «дерек жеткіліксіз» күйі көрінеді. Бұл жеке нақты дерек емес.
- `ai-journal.md` — осы сөйлесудегі нақты негізгі айналымдар мен түзетулер.
- Құралдың өзі — репозиторий түбіріндегі қосымша; іске қосу `README.md` ішінде.

Материалдар автордың тексеруіне арналған. OECD және GAO толық түпнұсқалары бұл ортадан ашылмады; дәріс арқылы берілген негіз түпнұсқамен толық оқуға тең емес. Нақты бағдарлама сынағы дерек сапасын тексерді; қажеттіліктен артық көлем тәуекелінің толық далалық валидациясы немесе дәлелденген бюджет үнемі ұсынылмайды.
