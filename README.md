# QARJY CONTROL · Value Gate 2

Бюджеттік өтінімдегі қажеттілікті құжатпен және қайта есептелетін ережемен тексеретін жергілікті цифрлық құрал.

**Бір кезең:** 1 — бюджеттік өтінім, қажеттілікті негіздеу. **Бір тәуекел:** қолдағы ресурс пен қызмет қажеттілігін тексермей, артық көлемге қаражат жоспарлау. **Дәрістегі құрал:** 1-құрал — бес сұрақтық бизнес-кейс (8-бет). Нарық медианасы бизнес-кейстің қосымша дәлелі ретінде қолданылады.

## 10 минутта іске қосу

Node.js **24.x** қажет. Windows-та жоба қалтасындағы **START-WINDOWS.cmd** файлын ашыңыз. Ол lockfile өзгергенде тәуелділіктерді орнатады, дерекқорды дайындайды, анық шартты DEMO-ны толықтырады және серверді іске қосады. Терезеде `Ready` шыққанда `http://localhost:3000` ашыңыз. Орнату жылдамдығы интернетке тәуелді; тәуелділіктер орнатылған соң PDF/OCR және есептеулер интернетсіз орындалады.

Қолмен:

```sh
npm ci
npm run db:init
npm run demo:seed
npm run dev
```

`npm run build && npm start` — production режимі. Сервер **127.0.0.1** адресіне байланған. Бұл жергілікті талдаушы құралы; көп пайдаланушыға арналған өндірістік жүйе емес.

## Алдымен не көру керек?

1. **DEMO → 6 сценарийді қосу.** 4 санаттық есеп, негізделген резерв арқылы жалған дабылды болдырмау және құжатсыз санға қорытынды шығармау мысалдары бар. Түпнұсқа орнына шартты TXT файлдар берілген. DEMO нақты сынаққа қосылмайды.
2. **Қажеттілік есебі.** Әр санның дәлелін ашыңыз: файл, бет, үзінді, құжаттағы сан, өлшем/кезең түсіндірмесі. Мәнді үзіндімен келіспейтін санға өзгертсеңіз, есеп «Дерек жеткіліксіз» болады.
3. **Құжаттар мен суреттер.** PDF, PNG/JPEG, TXT/CSV, XLSX (8 МБ) жүктеңіз; нақты бетін оқытыңыз; OCR мәтінін түпнұсқа бет суретімен салыстырыңыз. ЖСН, телефон және жеке мекенжайларды алдын ала алып тастаңыз.
4. **Нарық салыстыруы.** Кемінде 3 бөлек топтағы, сипаттамасы/өлшемі/ҚҚС/жеткізуі сәйкес, өзекті бағадан медиана. Қайталанған топ, бір файл немесе бірдей хэш бөлек көз болып саналмайды. Алып тастау себебі әр ұсыныста бар. А, Б, В белгілерін қолданыңыз.
5. **Бес сұрақтық негіздеме.** Қызметтік мәселе, кемінде 3 нұсқа (ештеңе істемеу де), бір мерзімдегі толық шығын, нарық және нәтижені кейін тексеруге жауапкершілік.
6. **Нақты бағдарлама сынағы.** 010 бағдарламаның портал кестесі мен тіркелген XLS деректерін салыстыру: 12 ортақ ұяшықта 7 сәйкессіздік; жыл бағандары бір жылға ығысқан. Нәтиже — деректі нақтылау; артық шығын немесе құқықбұзушылық анықталған жоқ.
7. **Нәтиже және есеп.** Толық HTML, 5 бөлімді түсініктеме, CSV, сақталған деректерден Excel (7 парақ), JSON. HTML-ді браузерде Ctrl+P арқылы PDF сақтаңыз. JSON файл байттарын қамтымайды; толық backup — сервер тоқтатылғаннан кейінгі `data` қалтасы.

## Санаттық ережелер

| Түр                      | Қажетті жаңа көлем                                                                             |
| ------------------------ | ---------------------------------------------------------------------------------------------- |
| Жабдық                   | max(0, ceil(қызмет көлемі / бір жабдық қуаты) + негізделген резерв − сәйкес қолжетімді жабдық) |
| Шығын материалы          | max(0, ceil(алушылар × норма × кезең + резерв − жарамды қалдық − расталған жеткізілім))        |
| Қызмет / лицензия пакеті | max(0, ceil(max(0, жұмыс көлемі − ішкі қуат) / бір пакет көлемі) + резерв)                     |
| Құрылыс / жөндеу         | Бір сметалық жол: өлшеу/ақау ведомосындағы физикалық көлем. Инженерлік сараптама жасалмайды.   |

Шығын материалында **бүтін дана/қаптама** немесе **бөлшек кг/литр/метр** режимін таңдаңыз: бөлшек көлем бүтінге дөңгелектелмейді. Салыстырылатын көлемдер бір өлшем мен бір кезеңде болуы тиіс. Белгісіз сан нөл болмайды. Бос активті немесе қызмет қуатын жеткіліксіз дерекпен шегеруге болмайды. Формулаға жарамайтын күрделі жобаға бұл үлгіні күштеп қолданбаңыз.

**KRI:** артық көлем белгісі бар құжатқа байланған көлем есептері / барлық құжатқа байланған көлем есептері × 100%. Дерексіз тексерулер бөлгішке кірмейді; қамту көрсеткіші бөлек беріледі. 0 бөлгіште пайыз жоқ. Баға ауытқуы бұл KRI-ге араластырылмайды.

## Нақты деректегі сынақ

Бағдарлама ID **3542837**, код **010**, әкімші **752**. Алынған күні **2026-11-02**. Қосымша `УОР - БП на декабрь.xls`, порталдағы қосылған күні **2024-12-17**, файл ID **3542841**. Қайта тексерілетін URL, парақ/ұяшықтар және файл SHA-256 ізі [docs/real-program-010.md](docs/real-program-010.md) ішінде.

Сынақ бір бюджеттік бағдарламаның дерек сапасы тосқауылын тексереді. Негізгі «артық көлем» тәуекелі нақты ішкі қажеттілік, ресурс және нормаларсыз толық валидацияланды деп көрсетілмейді. Жалған дабыл/өткізіп алу жиілігіне пайыздық баға беруге әлі негіз жоқ. 10 ойдан жасалған DEMO лоты нақты сынақтың орнына жүрмейді.

## Құжаттың шынайылығын не растайды?

Құрал файл байттарын сақтайды, SHA-256 есептейді және үзінді/сан байланысын тексереді. **Хэш пен OCR шынайылықты растамайды.** Маман құжаттың түпнұсқалығын, қызмет нормасын, кезеңін және нақты жағдайға сәйкестігін тексереді. Қолдан жасалған құжатты немесе байланысты компанияны бағдарлама өзі анықтамайды. Құжат сыртқы ЖИ сервисіне жіберілмейді; құжаттағы нұсқаулар орындалмайды. «Түпнұсқа» — жүктелген файлдың өзгертілмеген көшірмесі деген мағынада.

Бұл нұсқа сатып алуға келісім бермейді, ЭЦҚ тексермейді және үнем сомасын растамайды. Артық көлем немесе бағаның айырмасы үнем емес. Қызыл белгі — дәлел емес, назар аудару сигналы; белгі жоқтығы да дұрыстық кепілі емес.

## Деректер және үйлесімді жаңарту

SQLite: `data/qarjy.sqlite` немесе `QARJY_DB_PATH`. Ескі `datasets/history` кестелеріне жаңа интерфейс тимейді. Жаңа `audit_sets/audit_history/source_documents` кестелері бөлек, real/demo оқшауланған; нұсқа қайшылығы HTTP 409 қайтарады. Құжат байттары SQLite BLOB ретінде сақталады, файл жолы пайдаланушы атынан құрылмайды. Әр сақтауда тарихи нұсқа қалады; база әкімшісінен қорғалған аудит емес.

Бұрын енгізілген өтінімдер `/archive` бетінде қалады; негізгі үстелден таңдап көшіруге болады. Ескі келісім немесе «расталды» белгілері жаңа дәлел есебіне көшірілмейді. [Ескі модульдердің анықтамалығы](docs/legacy-manual.md).

Windows жаңартуы: серверді тоқтатыңыз, `data` көшірмесін жасаңыз, жаңа кодты бұрынғы жұмыс қалтасына көшіріңіз; `data` қалтасын өшірмеңіз. **START-WINDOWS.cmd lockfile өзгергенін байқап, жаңа PDF/OCR тәуелділіктерін де орнатады.** Ескі helper-дің Windows-та ашылуы пайдаланушының скриншотымен тексерілген; осы жаңартылған helper Windows-та жеке орындалып тексерілген жоқ.
