# QARJY CONTROL · Value Gate 1.0 MVP

Мемлекеттік сатып алуды жоспарлау кезінде қажеттілікті дәлелмен тексеретін жергілікті веб-қосымша. Бір кезең — жоспарлау; бір негізгі тәуекел — жеткіліксіз негізделген қажеттіліктен артық көлемге қаражат жоспарлау.

**Ескерту заңбұзушылықтың дәлелі емес.** Жүйе сарапшыны, мемлекеттік органның өкілеттіктерін алмастырмайды, сатып алуды тоқтатпайды және сыбайлас жемқорлықты автоматты дәлелдемейді.

## Орнату және іске қосу

Node.js **24.x**, npm 11 қажет. Орнатуға интернет керек; тәуелділіктер орнатылған соң қолданба интернетсіз жұмыс істейді. Шрифттер, диаграммалар және есептеулер сыртқы сервистерге тәуелді емес.

```sh
npm ci
npm run db:init
npm run dev
```

Браузер: `http://localhost:3000`. Алғашқы нақты дерек жиыны бос. Нақты статистика ойдан толтырылмайды.

Production режимі:

```sh
npm run build
npm start
```

Тексерулер:

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
```

Браузерлік тестке Chromium қажет. Linux-та `/usr/bin/chromium` автоматты анықталады; басқа орнатылған Chromium жолын `CHROMIUM_PATH` арқылы беруге болады. Балама: `npx playwright install chromium`. E2E production build-ті 3100 портында іске қосады және жеке уақытша SQLite базасын пайдаланады. Күнделікті базаға тест деректері жазылмайды. Скриншоттар `test-results/` ішінде.

## Технология және архитектура

Next.js 16 / React 19 / TypeScript, Zod, Recharts, ExcelJS, csv-parse / csv-stringify. Стильдер — responsive CSS, сыртқы CDN жоқ. SQLite үшін Node.js 24-тің `node:sqlite` API-ы қолданылады: жеке дерекқор сервері, ORM генерациясы мен native npm модулін жинау қажет емес. Prisma бұл MVP-де қолданылмайды; `npx prisma migrate dev` қажет емес. Қайталанатын орнату `package-lock.json` арқылы бекітілген. SQLite API-ының үйлесімділігі үшін Node 24 қолданыңыз.

- `lib/model.ts` — Zod модельдері, шектер, байланыстар және режимдер саясаты.
- `lib/calculations.ts` — UI мен DB-дан тәуелсіз, тестіленетін есептеулер.
- `lib/db.ts` — SQLite persistence адаптері, транзакция, optimistic version check, өзгеріс тарихы.
- `lib/files.ts` — CSV/XLSX импорт, экспорт, файл валидациясы.
- `lib/report.ts` — HTML түсініктеме жобасы, басып шығару / PDF.
- `app/api/store` — режим бойынша оқу және атомарлық сақтау.
- `app/api/files` — файлды тексеру, алдын ала қарау, экспорт.
- `app/page.tsx` — қазақ тіліндегі жұмыс кеңістігі, формалар, 13 бөлім.
- `tests/` — формулалар, дерек сапасы, алмасу, persistence тесттері.
- `e2e/` — нақты браузердегі толық пайдаланушы сценарийі.

SQLite автоматты дайындалады. `datasets(mode PRIMARY KEY, version, payload)` кестесінде `real` және `demo` бөлек агрегаттар бар. `history(id, mode, version, changed_at, payload)` әр сақтаудың бұрынғы нұсқасын сақтайды. Өтінімге активтер, баламалар, қаржы дәлелдері тиесілі; шешімдер, сынақтар және сыни бағалар өтінім ID-іне сілтейді. Журналдар қосу арқылы жүргізіледі. Өтінімді жойғанда байланысты шешімдер мен бағалар ағымдағы жиыннан алынады, ал SQLite өзгеріс тарихында сақталады. Бұл абсолютті қорғалған аудит емес.

Дерек файлы: `data/qarjy.sqlite`. `QARJY_DB_PATH` арқылы басқа толық жол беріледі (Next.js үшін `.env.local` не процесс айнымалысы). CLI `db:init` үшін айнымалыны shell арқылы экспорттаңыз. Нұсқалар мен тәуелділіктер репозиторийде, дерекқор мен жеке деректер Git-ке кірмейді.

## Негізгі жұмыс барысы

1. **Жаңа өтінім**: ID, орган, тауар, санат, қажетті нәтиже, жоспарланған сан, баға, қосымша қажетті орындар саны, ортақ мерзім, дәлелдерді енгізіңіз. ID өзгермейді; басқа өрістерді өзгерту және өтінімді жою бар.
2. **Активтер**: жалпы, қолданыста, жарамды бос, жөнделетін, жарамсыз сандарын енгізіңіз. Толық енгізілген бөліктердің қосындысы жалпыға тең болуы тиіс. Сәйкестік, қолжетімділік, тексеруші рөлі, тексеру күні және дәлелді белгілеңіз.
3. **Қажеттілікті тексеру**: тізілім толықтығын қолмен растаңыз. Расталған бос тізілім нөл актив бар дегенді білдіреді; расталмаған бос тізілім — белгісіз.
4. **Баламалар**: A–E түрлерін, жеті шығын көрсеткішін, бірдей нәтижеге сәйкестікті, қызмет мерзімі мен дерек дәлелдерін енгізіңіз.
5. **Қаржылық тиімділік**: бастапқы және таңдалған нұсқаны қолмен белгілеңіз. Нақты үнем үшін қосымша құжаттарды, дәлел дереккөзін, тексеру мәртебесін және қызмет нәтижесінің сақталғанын енгізіңіз.
6. **Тәуекел / шешім**: қосымша белгілерді тексеріп, мәселе, дәлел, ұсыныс, рөл, күн, шешім және негіздемені журналға қосыңыз.
7. **Сыни бағалау**: дұрыс белгілер, жалған дабылдар, өткізіп алған жағдайлар, дерек жетіспеушілігі және сарапшы қорытындысын тіркеңіз.

Әр сандық топтың дереккөзі, құжаты, URL, күні, сенімділігі және тексеру мәртебесі бар. Бір формадағы көрсеткіштер ортақ дәлел пакетіне сілтейді. Егер көрсеткіштердің дереккөзі әртүрлі болса, ортақ құжат өрісінде әр көрсеткіш пен тиісті құжатты нақты сәйкестендіріңіз; активтерді бөлек жолмен тіркеуге болады. Жергілікті құжат үшін URL бос қалуы мүмкін. Файлдың түпнұсқасы жүктелмейді: атауы / сілтемесі ғана сақталады. Сандық мән бос болса — **Белгісіз**, 0 деп енгізсе — нақты нөл.

Құжатты «тексерілген» деп белгілеу — пайдаланушының растауы; мемлекеттік жүйе арқылы тәуелсіз тексеру емес. ЖСН, телефон, жеке мекенжай енгізбеңіз; тек қызметтік рөлдерді пайдаланыңыз.

## Формулалар мен шектеулер

```text
PlannedCost = PlannedQuantity × UnitPrice
AvailableSuitableQuantity = расталған, сәйкес, қолжетімді бос активтердің қосындысы
JustifiedNewQuantity = MAX(0, RequiredQuantity − AvailableSuitableQuantity)
PotentialExcessQuantity = MAX(0, PlannedQuantity − JustifiedNewQuantity)
TCO = Initial + Installation + Repair
    + (AnnualMaintenance + AnnualOperation) × Horizon
    + Replacement + Other
PotentialCostDifference = MAX(0, BaselineComparableCost − SelectedComparableCost)
KRI = жеткіліксіз негізделген толық тексерілген өтінімдер / толық тексерілген өтінімдер × 100%
```

`RequiredQuantity` — қосымша қамтамасыз етілетін жұмыс орындары / алушылар. Қолданыста пайдаланылып жатқан активтерді қайта шегермеңіз; тек бос активтер есепке алынады. Жөнделетін актив жөндеу орындалмайынша жарамды болып саналмайды. Санат дәл сәйкес келуі тиіс.

TCO дисконтсыз, инфляциясыз және қалдық құнсыз. Жылдық пайдалану өрісіне жалдау ақысы да енгізіледі. Repair / Replacement / Other — бүкіл ортақ мерзімге жиынтық, AnnualMaintenance / AnnualOperation — жылдық. Қамтамасыз етілетін қызмет мерзімі талдау мерзімінен аз болса, балама салыстырылмайды; ауыстырумен ұзартылатын мерзімді тек дәлелмен көрсетіңіз. Екі ондық таңбаға дейінгі ақшалар тиынмен есептеледі, қауіпсіз сан шегінен асқан есеп қабылданбайды.

Сәйкес емес, дәлелі расталмаған немесе шығыны толық емес балама қаржылық салыстыруға кірмейді. Толық тексеру үшін кемінде екі сәйкес, расталған балама қажет. Ең арзан нұсқа автоматты таңдалмайды.

Ықтимал айырма **нақты үнем емес**. Нақты үнемге бастапқы құжат, бекітілген өзгеріс, нақты қаржылық нәтиже, нәтиженің сақталуы және қаржы дәлелінің расталуы қажет. Бұл пайдаланушының құжаттық растауы, тәуелсіз аудит емес. Нөлден жоғары үнем автоматты ойлап шығарылмайды.

KRI-де толық тексерілген, бірақ негіздемесі жеткіліксіз немесе қосымша белгілері бар өтінімдер алымға кіреді. Дерегі толық емес өтінімдер бөлек көрсетіледі. Бөлгіш нөл болса KRI жоқ. 0–100 тәуекел индексі қолданылмайды. Қосындылар тек белгілі мәндерді қамтиды; белгісіз мәндері бар жиын толық бюджет көлемі болып саналмайды. Әртүрлі өлшем бірліктерінің көлемдері ұйым бойынша салыстырмалы физикалық көрсеткіш емес.

## CSV / XLSX импорт және экспорт

«Сатып алу өтінімдері» және «Нақты деректермен сынақ» бөлімдерінен бос CSV/XLSX үлгісін жүктеңіз. UTF-8, CSV бөлгіші — үтір; ондық бөлгіш — нүкте. Алдымен бүкіл файл тексеріледі, содан кейін алдын ала қарауды растап сақтайсыз. Қате болса ешбір жол жазылмайды. Бар ID үнсіз ауыстырылмайды. Бір файл — ең көбі 5 МБ және 10 000 жол.

Өтінімдердің негізгі бағандары:

```csv
id,organization,title,category,plannedQuantity,unit,unitPrice,requiredOutcome,requiredQuantity,horizon
```

`horizon` — міндетті 1–50 жыл; сандар белгісіз болса ұяшық бос. Теріс, шексіз немесе жарамсыз сандар қабылданбайды. Құжаттардың қосымша бағандары: `source,document,url,date,reliability,verified,justification,inventoryConfirmed`. Күн: `YYYY-MM-DD`. Boolean: `true` / `false`. Сенімділік: `official`, `documented`, `unverified`; DEMO-да тек `demo`. Бос дәлелдер импортқа кедергі емес, бірақ есеп «Дерек жеткіліксіз» болады.

Толық экспортта `assets`, `alternatives`, `finance` бағандары JSON түрінде, барлық құрылымдарымен сақталады. Оларды импорттауға болады; файл тек өтінімдерді қамтиды, шешімдер журналының толық резервтік көшірмесі емес. Күрделі құрылымдарды формада толтыру ыңғайлы. XLSX бірінші парақты оқиды; формула / rich text ұяшықтары қабылданбайды. CSV экспортында формула инъекциясынан қорғау үшін `=,+,-,@` басталатын мәтіндерге апостроф қосылады; мұндай мәтіндер кері импортта апострофпен қалады.

Сынақ бағандары:

```csv
id,type,officialId,title,url,date,plannedQuantity,unitPrice,requestId,notes
```

`type`: `lot`, `program`, `protocol`. `requestId` бос болуы мүмкін; толық ішкі деректері бар нақты өтінімге сілтесе, есептеу жасалады. Бір ресми идентификатор бір түр шегінде қайталанбайды. URL ресми дереккөзге сілтеуі тиіс; жүйе оның түпнұсқалығын автоматты растамайды.

**10 лоттың болуы — 10 толық талдау емес.** Ішкі дерек болмаса: «Бұл лот бойынша негізгі тәуекелді тексеруге қажетті ішкі деректер жоқ». Нақты лоттар бұл репозиторийде ойдан жасалмаған.

## DEMO және есептер

DEMO батырмасы жеке дерек жиынына ауыстырады. «Мысалды жүктеу» шартты орган мен бір шартты өтінімді қосады; нақты деректер өзгермейді. Қайта жүктеу DEMO жиынын ауыстырады. Нақты және DEMO дәлелдерін араластырып сақтау серверде тыйым салынған.

«Есептер» бөлімінде төрт беттік HTML түсініктеме жобасын жүктеуге болады; оны браузерде ашып, Print → Save as PDF жасаңыз. Көлемді кестелер қосымша беттерге жалғасады. Сонымен бірге есептеу нәтижелері CSV/XLSX, ресми сынақ кестесі және нақты ЖИ журналы CSV экспортталады. ЖИ журналының толтырылатын үлгісі мен енгізу жоспары түсініктемеде бар.

## Құқықтық және университеттік шектеулер

- Қолданыстағы құқықтық редакциялар, нақты баптар мен жариялау күндері осы жұмыста ресми сайттардан тексерілмеді. UI: **«Қолданыстағы редакциясы қайта тексерілуі қажет»**.
- OECD Public Procurement және World Bank Procurement Framework әдістемелік бағдар ретінде көрсетілген; нақты басылымдарын тапсыру алдында тексеріңіз. [docs/methodology.md](docs/methodology.md).
- Дәрістегі алты құралдың тізімі берілмеген. «Дәрістегі таңдалған құрал — нақтылау қажет» өрісін әдістемеден толтырыңыз.
- Кемінде 10 нақты лот не бір рұқсат етілген ресми материал енгізілмеген; ресми API интеграциясы жоқ. Файл импорты жұмыс істейді.
- Үш нақты пайдаланушы–ЖИ диалогы берілмеген. Өткен диалогтар ойдан жазылмайды. Нақты итерацияларды интерфейсте тіркеуге болады. Әзірлеу тексерулерінің адал журналы: [docs/development-log.md](docs/development-log.md).
- Рөлдік авторизация, сыртқы серверге қауіпсіз жариялау, тәуелсіз растау, ұйымдарды оқшаулау, шифрлау және PostgreSQL — кейінгі кезеңдер. Бұл MVP жергілікті сенімді пайдалануға арналған. `next dev` / `start` 0.0.0.0-ге байланады; сенімсіз желіге авторизациясыз шығармаңыз.

## Сақтық көшірме және кейінгі даму

Серверді тоқтатып, `data/qarjy.sqlite` файлын көшіріңіз. Сервер жұмыс істеп тұрғанда тек негізгі SQLite файлын көшірмеңіз: WAL ішіндегі соңғы транзакциялар жоғалуы мүмкін. Кейінгі машиналарда сервер процесі қайта іске қосылады. Жаңа worktree қажет емес, осы checkout қолданылады.

Phase 2: сатып алу API, техникалық сипаттама және тауар баламалары. Phase 3: AI-assisted document analysis, құқықтық анықтамалық, тәуелсіз растау workflow. Phase 4: рөлдер, бірнеше орган, PostgreSQL, production қауіпсіздігі. Домендік есептеулер DB/UI-дан бөлек болғандықтан persistence пен интерфейсті кезеңмен ауыстыруға болады.

Нақты орындалған тексерулер және олардың шекаралары: [docs/validation.md](docs/validation.md).

## Жаңа бөлім: Актив жүктемесі

«Актив жүктемесі» бөлімінде ұйым, жабдық, ортақ өлшем, кезең, есептік қуат пен нақты пайдалану сақталады. Жүктеме = нақты пайдалану / есептік қуат × 100%. Нөлдік не белгісіз қуатта пайыз шығарылмайды. Сәйкестік, құжат немесе қуат негіздемесі расталмаса, тексеру мәртебесі «Дерек жеткіліксіз» болады; арифметикалық пайыз бөлек көрсетіледі. 100%-дан асқан жүктеме қиылмайды — қуат негіздемесін тексеру белгісі көрсетіледі.

30% бастапқы қарау шегі әр жазбада өзгертіледі; бұл заңдық норматив, аудит шегі немесе тәуекел ықтималдығы емес. Төмен жүктемеде резерв, маман, жөндеу, жолдамалар және география факторлары белгісіз/иә/жоқ ретінде тіркеледі. Резервтің қажеттілігі аппараттың аз қолданылуын негіздеуі мүмкін; жүйе нақты үнем не артық аппарат санын жарияламайды. Жүктеме жазбалары негізгі сатып алу KRI-не қосылмайды.

Нақты режимде «Шиелі аудит кейсін қарау» батырмасы 2026-10-14 ресми аудитінің деректері мен шектеулерін алдын ала көрсетеді; пайдаланушы растаған соң ғана нақты жиынға қосылады. 914 / 5080 = 17,99%; 56 484 700 ₸ — 2023 жылғы өтінімдегі жоспарланған сома, төленген сома немесе TCO емес. Дереккөз бен беттер әр жазбада сақталады. [Нақты деректің зерттеу есебі](docs/real-case-shieli.md).

Жүктеме жазбасын қосу, өзгерту, жою, SQLite-ге сақтау және CSV/XLSX экспорттау бар. Жүктеме кестесі негізгі HTML есебіне бесінші бөлім ретінде қосылады; PDF-ке браузерден сақталады. Жүктеме экспорты әзірге осы бөлімге қайта импортталмайды. Бұрынғы өтінім/сынақ импорты өзгермеген.

Бұрынғы деректер қорын өшірмей жаңарту: [Windows нұсқаулығы](docs/windows-update.md). Орта snapshot-ы жеке жарияланады; GitHub-қа жаңа кодтың жіберілуі Windows-тағы көшірмені автоматты жаңартпайды.
